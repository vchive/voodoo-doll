# P1 决策记录 · 模型编剧接入

日期：2026-09-17
状态：进行中（服务端已实现，等待模型供应商与密钥）

## 决定

把 002 spec 里 P1 的「可选编剧接口」（HF-18/19/20）提前到现在做，因为 002 的玩法形态
（玩家只能说话，娃娃是唯一能动手的手）在本地关键词匹配下体验受限：说一句不在词表里的话，
娃娃只会反问。真正好玩需要模型来理解。

## 边界（来自 spec，不放松）

| 编号 | 约束 | 本次实现方式 |
| --- | --- | --- |
| HF-18 | 超时/失败/禁用时回退本地站 | 服务端失败一律返回本地站结果，前端行为不变 |
| HF-19 | 密钥只在服务端 | 密钥读环境变量，不进前端、不进镜像、不进日志 |
| HF-19 | 输入长度/频率/超时/预算限制 | 见下表的限额 |
| HF-19 | 玩家输入不被当作工具指令执行 | 用户文本只作数据传入，不拼接进系统指令位 |
| HF-19 | 返回内容不得含可执行标记 | 前端与服务端双重校验，畸形响应直接丢弃 |
| HF-20 | 跨夜记忆引用具体讲述 | 历史对话作为上下文字段传入，不作为指令 |

## 限额（默认值，可调）

| 项目 | 默认 | 理由 |
| --- | --- | --- |
| 单次输入上限 | 200 字 | 玩家说的是心事的片段，不需要更长 |
| 每分钟请求 | 20 次 | 单人玩法的正常节奏远低于此 |
| 模型调用超时 | 8 秒 | spec 规定的默认值 |
| 每日调用上限 | 300 次 | 防止意外烧预算；达到上限回退本地站 |
| 历史上下文 | 最近 10 条对话 | 够娃娃记住上下文，又不会让 prompt 无限增长 |
