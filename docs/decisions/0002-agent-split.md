# 0002 · 玩家、娃娃与角色的 agent 划分

日期：2026-09-17
状态：**用户已确认**（2026-09-17，按此实现）

## 背景

用户提出：

> 巫毒娃娃是旁白，也是游戏中的一个娃娃，陪在游戏中的玩家身边。游戏里面的玩家角色的
> 行为是被巫毒娃娃操控的（相当于他俩共用一个 agent）。玩家跟巫毒娃娃对话，然后巫毒
> 娃娃给出建议，当然玩家也可以不采纳。

这里有一个内在张力，必须先解开：

| 主张 | 含义 | 推论 |
| --- | --- | --- |
| 「他俩共用一个 agent」 | 娃娃就是玩家的手，意图直接变行动 | 不存在"建议"这个环节 |
| 「娃娃给建议，玩家可以不采纳」 | 娃娃有自己的判断，与玩家意图之间有缝 | 它是独立的 agent，不是共用的 |

两者不能同时成立。

## 决定（建议方案）

**分开。** 但分法有讲究：

```text
玩家 ──说话──> 巫毒娃娃（独立 agent：有自己的判断、记忆、立场）
                    │
                    ├─ 建议：「今晚先别动他。」
                    │        ← 玩家可以不采纳
                    │
                    └─ 执行：玩家角色的身体 + 场上所有角色的调度
```

| 角色 | 是不是独立 agent | 掌握什么 |
| --- | --- | --- |
| 玩家（真人） | — | **发起权**：只有他能让事情开始 |
| 娃娃 | 是，且只有一个 | **执行权**：玩家角色的身体、场上调度、后果演出 |
| 玩家角色（B） | **不是** | 只是娃娃手里的一具身体，没有独立意志 |
| 其他角色 A/C/D/E | 各自是 | 自己的立场与记忆，会顶嘴、会拒绝 |

要点：**娃娃有"手"，玩家有"嘴"。** 玩家角色本身不是 agent。

## 理由

如果真做成"共用一个 agent"，娃娃会退化成操作界面：它不会劝你、不会迟疑、不会说
"我不太想演了"。而 002 spec 的第三层弧线（**由娃娃推动收尾**）正是建立在这个张力上——
一个只会执行的东西无法承担"劝你停下来"这个角色。

分开之后三件事同时保住：

1. **掌控感**：不发话什么都不动；玩家坚持时，娃娃即使不同意也照做。
2. **陪伴感**：娃娃是唯一会顶嘴、会心疼、会劝人的角色，这是"陪在身边"的实质。
3. **戏剧性**：其他角色各自独立，他们的反应不是玩家安排好的。

## 对实现的影响

| 位置 | 现状 | 需要改成 |
| --- | --- | --- |
| `server/orchestrator.js` | 只有其他角色是独立 agent | 增加娃娃自己的 agent 调用，产出「建议」 |
| 契约 | 只有 `ack`（复述理解） | 增加 `advice` 字段（可选，娃娃的判断） |
| 前端 | 确认后直接执行 | 先显示建议，再让玩家选采纳/不采纳 |
| `hello` 的角色表 | B 是 protagonist | B 保留为**玩家角色**，但明确它不是 agent |

关于 B：它仍然是玩家在戏里的身体，被娃娃调度。**不给它独立的 agent 调用**，
否则玩家会感觉自己的角色在自作主张——那会同时破坏掌控感和代入感。

## 与"旁白"的关系

用户说娃娃"是旁白"。现状里它确实是旁白（负责 `ack` 与收尾语）。本次调整让它在旁白之外
**多一个身份：有立场的建议者**。两个身份不冲突——它一边解说这场戏，一边对你说"我不太想演了"。

## 未决

- 娃娃的「建议」在多大比例上会出现？每次都出现会变啰嗦，建议只在特定情形（玩家明显在
  伤害自己、或娃娃迟疑值高）才出现。
- 玩家不采纳时，娃娃的态度要不要有可见变化？倾向要，否则"建议"没有重量。
