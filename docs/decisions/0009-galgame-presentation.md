# 0009 · 单人 Galgame 表现层

日期：2026-09-21。对应 MW-38 / SP-23 / MW-AC-38；依赖 MW-33–37。

用户确认：主界面应像 Galgame，有人物立绘和行动细节；手机横屏为主，旁白由巫毒娃娃承担。以下画面结构、资产选择及轻量动画是本轮实现默认，不代表用户已确认最终角色美术。

## 决定

- 默认单人界面采用 DOM 场景背景、在场人物立绘与底部统一对白/选择窗。DOM 直接承载可滚动文本、焦点、确认按钮及无障碍状态，适配短横屏。原 PixiJS 舞台保留在旧模式。
- `play-performance.ts` 只投影公开在场者、当前公开对白与确认回执；`play-stage.ts` 管理画面生命周期；`play-art.ts` 管理显式资源映射。世界时钟、NPC 日程、位置、行动成功与结局仍由 Python World Kernel 决定。
- 三名主要人物使用可追溯的默认立绘，共十张实际表情差分；只有原图所含的主体姿态。六张背景覆盖卧室、厨房、走廊、客厅、办公室和车站。其他地点用渐变背景，无对应立绘的人物用名字回退；不借用办公室图片冒充阁楼。
- 进入/退场、说话高亮、轻微晃动、场景淡入及动作短提示属于轻量表现。表情仅使用公开台词的明确词句作阅读提示，不推断角色私密心理，也不写入关系或记忆。没有骨骼、口型、Live2D 或完整动作姿态。
- 动作短提示只在本客户端收到本次确认回执后播放，以 eventId 去重。预览、取消、读句、回看、刷新和迟到的旧版本回执不触发新行动。离线规则玩法继续保留，但本轮未补齐离线同等动作演出。
- 图片使用同源构建资源，加载失败仍可读文/选择；尊重减少动态设置。署名保存在仓库及游戏菜单，历史付费测试素材不进入构建。

## 影响与边界

没有改变 API、存档协议或角色日程；不需要存档迁移。新视觉增加约 1.64 MB 的位图资源，浏览器按当前场景和人物表情加载，并未把全部图片嵌入入口脚本。素材是现有授权作品，后续原创角色设计可替换资源映射。

行动预览与结尾选择有独立的窗口高度，确保正文和确认/退出按钮在短横屏可见。验收保留原教程、旧 v1/v2、离线恢复及多标签边界；桌面模拟与微信真机分别记录。证据见 [Galgame 舞台验收](../evidence/2026-09-21-galgame-stage.md)。
