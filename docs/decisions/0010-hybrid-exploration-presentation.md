# 0010 · 俯视探索与 Galgame 人物融合

日期：2026-09-21。对应 MW-39 / SP-24 / MW-AC-39，依赖 MW-33–38。状态：本机桌面已测范围完成，见[融合舞台证据](../evidence/2026-09-21-hybrid-stage.md)。

用户确认：将此前俯视图与 Galgame 立绘融合。横屏优先、统一对话窗、娃娃旁白与角色日程仍为既有要求。以下画面结构、自动切换和人物点选均是实现默认，不代表用户逐项指定或已认可最终构图。

## 决定

- 同一公开快照同时驱动俯视房间与人物立绘。`play-overview-model.ts` 投影在场与展示站位，`play-overview.ts` 复用 PixiJS、合法房间元件和像素角色绘制；`play-stage.ts` 组合俯视与既有背景/立绘。直接适配当前单人快照，不加载旧夜场编排，也不把旧 renderer 的状态与娃娃执行逻辑接回新世界。
- 横屏探索时左侧俯视房间、右侧当前对白/选择窗，保证短横屏仍看得清布局。阅读时改为底部宽文字窗、右侧人物立绘、左上小俯视图，保留所在位置感；竖屏继续使用上方场景与下方文字窗。只有一个文字窗，布局变化不复制对白或增加另一套阅读游标。行动预览在两种模式下均保持足够的正文与确认/取消空间。
- 默认按阅读和行动状态自动构图；“看场景 / 看人物”只覆盖当前读/选阶段的画面偏好，读/选阶段、worldId/worldVersion 或 roomId 变化后恢复自动默认。镜头选择不写进权威世界、不移动玩家、不推进对白，不提交意图或额外行动耗时，也不冻结自然时钟。
- 俯视图展示 YOU 及当前公开在场 NPC，娃娃作为随身小物附着 YOU，不是独立身体；YOU/DOLL 共用一个执行 Agent 的边界保持。NPC 用稳定 ID 对应当前角色；点击只打开 YOU 交谈的现有可见预览，玩家再确认或取消，且不覆盖原来另写的自由输入。预览/busy 时防重复；最终确认继续由服务端检验版本、能力和在场。离场或退场残影不能保留交互，旧对白回看不能重新安置离场人物；离线关闭 NPC 热点交谈，保留本地探索入口。
- 室内布局与小人站位仅是展示示意。没有新增连续移动、点击地面寻路、精确距离、家具交互或 NPC 控制协议；到其他地点继续走现有地图、推荐和自由输入。已注册物件与服务器状态不因房间图上画了家具而改变。
- 主舞台实例保留，故事库往返或重建时调用 `settle()` 暂停 ticker、清理当前演出，返回后重新观察当前对白并投影新快照；不宣称每次离开都销毁实例。俯视适配器另有 `destroy()`，支持最终卸载释放画布/ticker/可见性及动态偏好监听，异步初始化检查销毁状态。减少动态关闭非必要循环/移动。渲染器或素材失败时保留平面表现、角色名字及原行动入口；离线使用本机快照，不伪装成服务器确认。

## 影响与验收

本轮只改表现与交互入口，无 API 或存档迁移，不重置当前故事、事实、位置或结局。MW-38 的素材授权、未知人物名字回退、已确认动作按事件去重及私密心理边界继续有效。旧模式仍保留回滚，但切换“看场景”不是进入旧模式。

MW-AC-39 A–F 分别记录双表现、只读切换、NPC 点选、横竖短屏、故障/减少动态与存档回归。本轮最终独立浏览器 40/40 通过：四尺寸融合和各自旋转覆盖阅读/未发草稿/pending，A 热点预览/取消/确认保持原草稿，A/B/C 按日程从两个表现同步离场，渲染器失败仍可移动/开门；原新旧故事及恢复回归保持。Node 125/125、类型检查及双构建通过，Python 未改未重跑。短横屏探索的侧窗与阅读的底窗分别做几何断言，确认按钮与结尾出口可达性未放宽。

减少动态的浏览器零动画断言直接覆盖 DOM，Pixi ticker 分支为实现检查；热点连击、预览恰好跨时段确认和适配器 `destroy()` 独立调用未单列浏览器组合。微信真机、真实软键盘、公网、完整美术、连续空间模拟与完整肢体演出继续另验。完整计数与截图见[最终浏览器报告](../evidence/2026-09-21-hybrid-stage-browser.json)和证据页，不将自动操作时长当作玩家阅读时长。
