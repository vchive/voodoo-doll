# 0011 · 角色生活对话与关键剧情分流

日期：2026-09-21（Asia/Shanghai）
状态：方向沿用用户的独立角色、多 Agent 世界与 SDD 要求；以下分流粒度为本轮实现默认，MW-43 本机有限范围已验。

## 原因

signal 教程原先对同场主要角色的所有提问都优先返回章节稿，角色 Adapter 即使存在也无法参与普通聊天。直接移除章节稿又会失去当前教程的证据、时间窗与结局约束。因此先接通林川的日常对话，再扩展其他人物与自主生活。

## 决定

- 普通生活聊天确认后走现有角色 Adapter，关键剧情话题保留确定性稿件。只有玩家明确的受支持命令或推荐动作可选择立场，角色回复不替玩家取得证据或选择结局。
- 对话请求仅增加本人的名字、人设、性格、目标及当前日程活动/时钟。继续使用本人可见事件和隔离记忆；嵌套白名单不透传全量 profile、未来日程或全局剧情资料。
- 人格与目标本轮只影响回应上下文，不意味着角色已经自主计划或执行任务。未被接触人物沿用已有惰性时间/位置投影，不新增模型空转。
- 无配置或失败时给出有主题的本地回应，有限回忆只引用本人已提交的玩家原话。预览与取消不生成回复或记忆；确认、幂等、在场和版本校验沿用 Kernel。
- 普通聊天仍消耗世界时间，可能错过当前窗口。教程与生活两类推荐使用现有交互，无新存档协议、无玩家进度迁移。

## 代价与后续

首版分流使用有限话题和明确命令匹配，会拒绝一些含蓄表达；推荐动作提供稳定入口。B/C 仍为稿件，真实模型事实一致性仍须单独验证，提示词不能保证正确。后续应在实际模型评测和语义意图提案完善后扩大表达范围，仍由权威规则确认世界变化。
