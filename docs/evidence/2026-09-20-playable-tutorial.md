# 2026-09-20 · 《雨停以前》实际可玩短篇验证

对应 004 `MW-28 / SP-11, SP-14 / MW-AC-28`、`MW-29 / SP-12, SP-13 / MW-AC-29`。这是首个完整短篇闭环的本机证据，不是用户期望的长篇内容全部完成，也不是公网或微信真机发布。

## 实际实现

- 新玩家可选“开始新手故事”或“自己设计世界”；已有玩家从“故事库”进入。故事预览确认后才开始；新篇章开始前按草稿 ID 保存一次原进度备份，从“旧进度”可导出。
- `backend/app/narrative.py` 实现原创五章、10 次标准确认行动：观察便笺、开客厅门、去地铁站、开玻璃门、去办公室、完成校对、询问林川、相信/追问、回家、开家门。标准行动时间合计 39 游戏分钟；没有测得或承诺 60–120 分钟游玩时长。
- 章节、分支、工作标记与动作耗时在 Kernel 同一事务保存。客户端只渲染 guidance，不用本机教程步骤决定剧情。世界时钟亦会按服务端真实时间前进。
- 林川 09:00–10:00 在办公室，之后回家。晚到有独立结局；错过后去家里对话也不能套取已经失效的限时剧情。模板之外不注入这段故事。
- 每个地点的门注册为数据实体。输入“去开门，看看里面有啥东西”在地铁站执行玻璃门 open，有具体中文反馈及开关状态。
- 推荐动作由服务端按场景与章节投影；保留自由输入。未知输入保留原文并提示推荐动作，不把失败伪装为观察/移动成功。
- 阅读/预览超过角色租约时限后可续租。仅系统时间/位置/租约事件造成的版本变化可重基，真实玩家并发仍拒绝。

## 仍未完成

- 当前是10次行动可通关的短篇底座；长时间游玩的章节密度、多日生活、完整工作/上学经济后果、多人物路线、更多场景仍需扩写与实际评测。不能称完整长篇教程已完成。
- 无模型时服务端短篇完整可玩。完全断开本地服务时只支持明确标识的本机探索（移动、门、观察、等待）；章节停在上次快照，不宣称离线长篇通关。首次离线新手模板提示重试或自定义探索。
- 本轮浏览器未注入确认响应丢失、存储配额耗尽或网络中断矩阵；备份与离线恢复相关修改做了代码审查，关键叙事导入另有服务端测试，不能混同浏览器实测。
- 自定义世界目前保留已有简单初始日程与固定地点，尚不能从任意叙述自动生成完整世界。开源调研见[来源记录](../research/2026-09-20-playable-galgame-sources.md)，未引入第三方运行时或商业游戏文本素材。
