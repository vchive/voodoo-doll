- 纯函数测试：存档迁移、人物对键、法力边界、仪式幂等与取消、剧本结构验证。

- HTTP 集成：正式服务路径/状态/MIME/目录边界，不只 mock 文件读取。
- 真机手工验收：微信聊天链接、键盘、全屏/常亮/传感器、声音与后台；无法自动化的项目保留明确步骤。
