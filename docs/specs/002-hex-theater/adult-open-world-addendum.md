# 002 增补提案 · 开放世界与成人向表现

状态：**提案，未实现、未验收**（2026-09-18）。本文把用户提出的“开放世界、可配置成人向/R18 表现、多人关系事件”拆成可执行的规格边界；它不改变当前 002 的非露骨默认行为。

## 产品边界

“开放世界”先定义为**可扩展的关系舞台**：房间、街区、人物槽位、物件和事件由注册表驱动，玩家可以在多个地点往返，事件会因为人物记忆和关系状态改变。首版不承诺无限地图、自由生成建筑或持续在线世界；这些能力需要独立的性能、存档和审核预算。

“成人向”先定义为**成年虚构角色的成熟主题**（背叛、暧昧、夜生活、冲突、黑色幽默和含蓄的亲密关系）。默认模式不渲染露骨性行为，不把真人或可识别个人作为目标，也不把伤害真人的操作映射成现实行动。若将来要加入更高强度的 R18 视觉层，必须另立版本、资源包和合规审查，不能仅靠模型提示词开启。

以下为新增需求提案，`P0` 表示开放扩展的基础，`P1` 表示成人向表现层；未获产品确认前，按当前非露骨实现执行。

## 需求

| ID | 优先级 | 可验证行为 |
| --- | --- | --- |
| OW-01 | P0 | 世界由 `world → zones → rooms → props → anchors` 注册表组成；增加一个房间只需新增数据和素材，不改 Agent 核心循环。 |
| OW-02 | P0 | 玩家可从当前房间进入至少 3 个相邻地点；进入、离开、时间和天气写入世界状态，并影响下一次造景。 |

| OW-04 | P0 | 每个角色档案明确 `adult: true`；年龄未知、年龄冲突或疑似未成年时，关系事件和成人主题自动降级为普通对话并记录原因。产品不提供未成年角色的成人化选项。 |
| OW-05 | P0 | 角色与世界存档按匿名会话隔离；玩家输入、私密记忆和成人偏好不出现在其他会话、公开战报或路人 Agent 的上下文中。 |
| AD-01 | P1 | 内容级别至少有 `general`（默认）和 `mature`（用户主动开启）。`general` 不出现露骨性行为、裸露描述或性化镜头；`mature` 允许成熟关系、暧昧和含蓄的镜头语言，但仍遵守服务端禁用类别。 |
| AD-02 | P1 | 开启 `mature` 前显示年龄确认、内容说明和关闭入口；设置保存在本机，服务端只收到经过校验的级别，不接收身份证件或头像。未完成确认时使用 `general`。 |
| AD-03 | P1 | 所有模型输出先经过服务端内容策略：角色年龄、参与者同意状态、主题级别、现实人物指向、工具动作和长度均由契约校验；违规结果丢弃并使用本地安全模板，不把原文回显给玩家。 |
| AD-04 | P1 | UI 不把 `mature` 做成一次性不可逆开关；玩家可随时降级、隐藏相关事件和清除本机成人偏好。降级只影响后续生成，不篡改已确认的普通记忆。 |
| AD-05 | P1 | 成人向表现只影响台词、灯光、镜头和关系状态；不增加拖拽真人、现实地址、外部联系方式、支付或骚扰功能。娃娃、环境和角色 Agent 仍不能访问 Shell、文件、网络或其他玩家数据。 |

## 验收

| ID | 验收条件 |
| --- | --- |
| OW-AC-01 | 在无模型模式下从三个地点往返，刷新后恢复当前地点、时间、天气和关系状态；新增房间不需要改编排器代码。 |
| OW-AC-02 | 两个匿名会话使用相同角色名和事件输入，服务端日志、记忆和战报互不可见；未知会话不能用 `worldId` 读取世界。 |
| OW-AC-03 | 角色年龄缺失、冲突或标记为非成年时，`mature` 事件被拒绝并回退普通模板；契约测试覆盖模型伪造年龄和工具参数的情况。 |
| AD-AC-01 | 新会话默认 `general`；未确认年龄时不能得到 `mature` 结果；关闭或降级后下一次生成不再使用成人向提示。 |
| AD-AC-02 | 针对同一输入分别生成 `general` 与 `mature` 草稿，前者不出现露骨内容，后者只在允许的成熟主题清单内变化；模型失败、超时和策略拒绝均能完成本地演出。 |
| AD-AC-03 | 成人偏好、年龄确认和相关记忆不进入公开战报、分享图或 ENV/Z 的上下文；清除偏好后重新打开页面保持默认级别。 |
| AD-AC-04 | 320/390/430 CSS px 下年龄确认、内容级别、降级和退出控件可触控，文案不遮挡房间和状态栏；桌面模拟与微信真机分别记录。 |

## Agent 与世界规则

- 娃娃 Agent 负责将玩家叙述转成场景与建议，不能凭空增加年龄、关系事实或同意状态；不确定时进入澄清或本地安全模板。
- A/B/C 各自只收到已确认的公开事实、自己的私密记忆和当前舞台事件；成人偏好是世界策略，不作为角色私信广播。
- ENV 只反馈灯光、天气和物件现象；Z 只用本地模板。两者不判断玩家输入，也不生成成人向细节。
- 编排器先做世界注册表与内容策略校验，再调用模型；模型返回的房间、角色、物件、动作、内容级别和年龄字段全部做白名单校验。校验失败时整段草稿作废，不部分提交。
- `mature` 不是 Agent 的工具权限。任何级别都不开放 Shell、文件读写、外链、现实人物检索、联系人或消息发送。

## 风险与发布门槛

- **年龄误判**：只用模型推断年龄不可靠；必须使用角色档案的显式成年标记，缺失即降级。
- **提示词注入**：玩家自由输入不能改变内容级别、Agent 权限或世界注册表；策略和契约在服务端执行。
- **素材许可**：成人向图层和人物包需逐项记录作者、许可和分发范围。当前 LPC 合成图只在 `hex/selftest/lpc` 自测，不随生产构建发布；Donarg 付费图块继续排除。
- **平台差异**：微信 WebView、IP 直连和正式域名对年龄提示、缓存和本地存储行为不同；开放 `mature` 前必须完成真机与公网测试，并准备平台下架/关闭开关。
- **数据与合规**：不收集身份证件；只保存最小化的年龄确认结果和内容级别。服务端日志不得保存未经处理的玩家原文或成人草稿。

在 OW-AC 与 AD-AC 全部通过、资源许可清单完成、真机和公网环境分别记录之前，发布配置固定为 `general`，并把本增补标记为未启用提案。
