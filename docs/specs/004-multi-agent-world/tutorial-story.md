## 需求与本次默认

用户要求新手任务本身能作为一段完整游戏游玩：有剧情、有生活主线、有环境行动、有推荐选项，也允许自由表达；NPC 根据日程出现，错过时间就会失去机会。用户偏好《Fate/stay night》，希望借鉴优秀 Galgame，在制作教程的过程中完善游戏能力。

用户进一步提供 Galgame 文字窗图片，要求提示像游戏对白一样显示人物在说什么或思考什么。本次采用角色名牌与文字窗，按句呈现原创对白、主角心声和环境叙述；图片只作为呈现形式的参考。逐句方式、键盘阅读、记录和提前展开行动是本次实现默认。

本次采用原创《雨停以前》，以日常生活引入异常线索，让玩家通过同伴、证据与限时选择形成自己的立场。这些是对经典 Galgame 叙事组织的参考；本篇使用本项目原创角色、场景、对话和事件。档案馆、校对员、林川和 10:00 截止时间是 v2 的实现默认；“五章”只描述 v1 兼容模板，不代表用户指定了这些细节。

当前目标分为两个层次：默认教程使用 v2 的三日闭环，旧 v1 仍保留兼容和回归；后续再把 v2 的角色路线扩写成更长的多日世界。v2 的标准主线由多个移动、观察、工作、交谈和选择节点组成，第二天有地铁站与厨房两条线索入口，第三天汇总证据并收束路线。v1 的第二天旧伞支线继续作为旧档恢复测试，不改变 v1 已有结局。耗时是游戏内时间，不等于真实游玩时长；长篇章节、更多人物路线、反复游玩内容与更丰富演出仍需继续制作和试玩。不承诺 60–120 分钟内容已经完成。

## v2 完整故事：三日的回执

你是城市档案馆的新任校对员。第一天早上，桌上出现一张写着“明天”日期的通行证，巫毒娃娃小墨只提醒你先去上班。林川在办公室等你，他想谈一封辞职信；地铁站的玻璃门后，则有一张末班车被延后三分钟、司机姓名被擦掉的告示。你必须在工作和调查之间安排时间，十点前仍有机会听林川解释。

第一天的选择不是简单的好坏判断。你可以先相信林川，让他和你共同署名；也可以要求证据，把修改记录和责任一起留档；如果在窗口关闭前没有完成交谈，林川会按自己的生活表回家，故事留下 `missed` 结果。无论哪种结果，主人公的校对工作、地点和已经发生的事件都保存在同一个世界中。

第二天，通行证背面出现编号 `06-17`。玩家可以赶在周野交班前去地铁站，询问旧伞和交接卡；也可以在沈青准备午饭时去厨房，听她保留的旧录音。两条入口都能把线索带回办公室，但人物只在自己的公开时间窗里出现。周野离场后只能查公开登记，不能伪造他的当面对白；沈青离开厨房后，录音仍是可观察的物件，但当面追问机会已经结束。

第三天，档案馆的收件台出现一张未来回执。林川说明通行证不是预言，而是档案馆提前生成的收件记录：有人希望这次更正能留下署名，才把它先放到你的桌上。玩家根据前两天收集到的证据决定最后一页的处理方式：共同署名（`trust`）、公开审计（`audit`），或先保护林川、暂不公开（`protect`）。第一天的回应会改变关系和可见线索，但不会锁死最后的立场；第三天确认的最终回应才是权威结局选择。三条路线会留下不同的后记和公开事实，随后回到家中，世界进入教程完成后的自由状态。

v2 的谜底解释了通行证来源，但不会替玩家决定立场。每条路线都保留人物的生活后果：林川仍要照顾父亲，沈青和周野按日程离开，主人公的工作状态继续存在。教程的开放世界重点是“人物不会为了玩家停住”，而不是让模型逐分钟模拟每个人吃饭或工作。未进入玩家兴趣范围时只更新公开驻留投影，玩家靠近或发起交互时才激活角色。

## v1 兼容故事梗概（旧档）

本节只描述 `rainy-office-v1` 的五章旧存档内容，用于迁移回归和已存在存档的继续游玩。它不是当前新建世界的默认教程；新玩家应以本文件前面的 v2 三日主线为准。

你是城市档案馆的新任校对员。上午九点，连下三日的雨还没有停，家中桌上却多出一张印着明天日期的通行证。巫毒娃娃小墨没有解释它的来历，只提醒你先照常去上班。另一张便笺写着同事林川的请求：十点前来办公室，他想谈一封尚未寄出的辞职信。

开门时，你发现一把滴水的旧伞，伞柄上的日期与通行证相同。通勤经过地铁站，玻璃门后的停运告示吸引了你的注意：末班车的发出时间被改晚了三分钟，司机的名字却被抹去了。值班员周野仍在检票，城市没有为了你的疑问停下来。你抄下时间，继续去办公室。

值班表上有你的名字，今天恰好由你校对这份告示。十分钟的工作让你核对了日期、时刻和原稿，也在原稿背面找到被划去的名字。小墨帮你压住纸角，但工作需要你完成。你既是故事里的调查者，也是有职责、需要到岗的人。

林川不断看钟。他十点必须回家照顾父亲，没法整天等候。他说，最后一班车为了救人多等了三分钟，救人的司机却被从档案里抹去了。他想辞职，又不甘心让这件事消失，于是把信和原稿留给你。你可以先相信他的求助，也可以追问他究竟隐瞒了什么。

相信他，你会把司机名字补回校对页，林川答应与你共同提交原稿。要求证据，他会承认自己亲手擦掉过名字，因为害怕自己也被忘记；你要求把修改记录与更正说明一起留下。两个选择都让事件走向可追溯的更正，也保留了不同的人物关系和态度。

回家后，通行证渐渐变干，明天的日期不再像一个威胁。小墨问你：“明天，还去上班吗？”故事以各自的后记收尾，世界仍有其他人物和日常活动。通行证为何提前出现作为后续扩写线索保留；本篇“被抹去的司机名字是否留下”已经有明确结果。

如果你在十点前没有完成关键回应，林川会按日程回家，桌上只留下封好的信。这次当面解释的机会结束，短篇呈现“迟到的人”结局。你仍能完成工作、探索城市、与当前在场的人交流。错过机会是实际结果，不能靠刷新页面重开。

## 第二天可选支线：伞柄上的编号

主线结局不会关闭世界。无论玩家选择相信、追问，还是错过林川的窗口，回到家后都可以从推荐动作进入第二天支线。支线不改写已经获得的 `ending`，它用同一套移动、观察、询问和物件交互原语，让玩家练习“NPC 会离场，但公开世界仍能继续提供线索”的玩法。

| 支线章节 | 进入条件与推荐动作 | 已确认事实与线索 | 替代路径 |
| --- | --- | --- | --- |
| 第六章 · 伞柄上的编号 | 主线 `complete` 且 `postscript=ready`；选择“去地铁站” | 抵达地铁站后进入 `postscript=station`；旧伞编号尚未写入记录 | 只能从主线结局后进入，不重开主线选择 |
| 第七章 · 失物登记 | 在地铁站询问周野“伞柄上的日期是什么？” | 周野说明旧伞曾登记、没有留下姓名，写入 `station-pass` | 周野已离场时观察失物登记处，写入 `station-pass-late`；不伪造周野对白 |
| 第八章 · 档案背面的地址 | 根据推荐动作回办公室，检查办公桌/旧卡片柜 | 找到与伞柄同日的转交记录，写入 `archive-card` | 只要支线已进入 `office`，移动和物件检查顺序可从存档恢复 |
| 第九章 · 明天的日期 | 带记录回家并开门 | 支线 `postscript=complete`；编号、卡片和更正页被放在同一文件夹 | 仍保留自由探索；支线完成不锁住主线世界 |

支线的周野回应只在周野位于地铁站且玩家确认行动时产生。玩家先进入地铁站再等待到周野离开，仍可通过观察登记处继续；该动作给出公开环境结果和下一步推荐，不把角色 Agent 的私密推理写进场景。支线允许导出/导入，旧版没有 `postscript` 字段的主线存档按 `ready` 兼容并可继续。

支线的 SDD 退出条件是：主线结局保持不变；在场与离场两条路径都能到达 `postscript=complete`；每个线索有事件或快照证据；预览/取消不推进；导出/导入保留支线步骤；无模型仍可完成。浏览器 320/390 宽度、微信真机、公网和网络故障矩阵仍单独验收，不以 Python 回归替代。

| 共同署名 `trust` | 主人公相信林川的求助；后记中两人共同交原稿，司机名字恢复 | 选择保留，继续同一世界；后记的翌日展望不等于偷偷修改当前世界时钟 |
| 留下证据 `question` | 修改记录与更正说明入档；林川承担自己的责任，主人公坚持证据 | 选择保留，人物仍有自己的生活；后续人物路线待扩写 |
| 迟到的人 `missed` | 错过当面解释，林川回家，信已封好；本篇窗口结束 | 自由行动继续，未完成的校对仍可做；刷新或调整设备时间不重置机会 |

## 引导、自由表达与恢复

章节区显示当前目标，剧情通过文字窗逐句呈现；推荐区给出能在当前世界执行的行动，并显示预计耗时与必要原因。读完本段再展示推荐选项，也可提前展开行动。地点、物件和人物交互都经过已有预览/确认流程；点击推荐按钮不能绕过世界规则。自由输入始终保留，让玩家用自己的话表达。当前未支持的物件/动作不生成伪造的成功事件，而是解释限制，留下输入，并让玩家直接选一个可执行动作继续。

章节、工作和结局由服务端世界记录保存；`guidance` 是它们的公开展示投影。本机缓存可记录显示偏好，必须绑定 worldId，不负责判定章节成功。刷新、进程重启与导入恢复到同一世界已经确认的位置；故事和行动取消不推进，重复确认只返回既有结果。

无模型配置下，原创章节、本地人物回应与环境结果仍能通关。人物的沉默和拒绝必须有可读的表情或动作，使玩家理解这是一种回应；不能让通关依赖反复输入碰运气。离线试玩必须明确自身状态，不能把本地模拟结果当作服务端世界事实。

## 非线性教程事实推进

教程目标读取服务端已经确认的事实集合，而不是读取玩家是否按推荐按钮操作。事实至少包括当前地点、已经打开的门、已阅读的线索、已完成的工作、已确认的选择和已关闭的时间窗；推荐动作只是从这些事实计算下一步入口。这样玩家先开门再读便笺，仍然完成“开门”事实后继续阅读，不会因为顺序不同被送回开门按钮；玩家已合法移动离开客厅后，也不再要求重复“出发”。

每次确认都由 Kernel 重新验证事实、在场和版本。若旧存档的教程游标与事件事实错位，服务端在同一事务中写入一条带原因、旧游标、新游标和幂等键的纠偏记录，并根据事实选择尚未完成的目标。纠偏不补玩家没有阅读的便笺/告示，不重演已展示对白，不恢复已错过的林川窗口，不改变已有结局或额外消耗世界时间；重复恢复只返回同一修正结果。纠偏后界面要说明“已识别你之前完成的行动”，同时给出下一项可执行推荐。

## 周野交谈与上下文接话

周野在地铁站的公开回应不是通用占位语，而是四个可继续的话题。每个话题都产生可观察的新信息，并把下一句或推荐行动放回当前在场状态。

| 话题 | 周野的具体回应 | 可继续的动作 |
| --- | --- | --- |
| 日常 | “今天雨下得比预报久。九点前的班次都按表走，九点以后要看站内告示。”他指了指检票机旁的值班表。 | 询问告示、查看值班表、前往办公室 |
| 站内告示 | “玻璃门后的告示刚换过，末班车被改晚三分钟。原来的司机姓名被划掉了。”他确认门锁已经解除。 | 打开玻璃门、追问三分钟、记录告示 |
| 三分钟 | “那班车多等了三分钟，是为了让一个淋雨的人上车。记录里只留下‘临时停车’，没有司机名字。” | 询问是谁、带告示去办公室、前往办公室 |
| 后续追问 | “我只看过交接本，不能替档案馆认定是谁。但你若要查，原稿背面的涂改痕迹比传闻可靠。” | 接受线索、继续追问、去办公室校对 |

周野可以沉默、看表或指向门，但沉默也要有可观察的叙述和当前可执行动作，不能返回空白回应。具体回应只在周野位于地铁站且当前时间仍在公开值班表内时开放；离开地铁站或超过窗口后，旧话题不再强行延续，界面显示他已去往下一处日程并推荐当前在场对象或生活行动。

玩家说“说什么”“什么意思”“然后呢”“继续说”等接话表达时，解析器先查最近一段已确认、仍在同一兴趣范围内的公开对话对象，再把表达绑定为该对象的 `continue_dialogue`。若当前只有一个可交谈对象，即使没有上一句也可以把表达补全为询问该对象；若有多个可交谈对象且没有有效上下文，界面必须先让玩家选择人物；若最近对象已离场，则返回在场校验错误和新的推荐入口。接话仍需经过预览、确认和服务端版本校验，不通过阅读游标直接推进对白。

任意未知物件或动作，例如“打开不存在的暗门”，不能因为句式像提问就降级为聊天。解析失败保留原文和用户记录，直接展开当前章节推荐、在场可交谈人物和恢复按钮；玩家不必先读完文字窗才能离开错误状态。错误恢复只改变展示状态，不自动重试、确认或推进时间。

## 对话窗与逐句演出

每个已确认阶段提供一组公开演出句，文本跟随当前故事状态，不能提前展示未选择分支或未揭示的线索。`guidance.dialogueId` 标识当前文本组，`dialogue` 每句含 `speakerId`、`kind` 与 `text`；正文窗显示当前说话者名牌与类型，支持点击和键盘前进，也能回看本段记录。

| 演出类型 | 本篇用途 | 信息边界 |
| --- | --- | --- |
| `speech` 公开对白 | 小墨的提醒、林川的陈述、主人公已确认立场的表达 | 只显示当前阶段可公开的纯台词，第三人称动作另作叙述；不替玩家完成尚未确认的选择 |
| `thought` 主角心声 | YOU 对日期、三分钟与证据的感受和自问 | 仅允许 YOU；不显示 NPC 内心答案，不由界面读取私密记忆 |
| `narration` 环境叙述 | 雨声、纸张、神情、门后景象与已发生行动的反馈 | 只描述已公开场景和可观察行为，不把推测写成角色真实意图 |

多句阅读只调整本机显示游标，并按 worldId/dialogueId 保存；刷新可继续当前句，“回看本段”只显示当前段落已显示到当前位置的文本。新阶段重建相应文本组，切换世界不能串用游标。阅读、展开行动和查看记录不触发 Kernel 行动、不额外消耗游戏时间、不完成目标；世界自然时钟照常运行。为让玩家能赶在 NPC 离开前行动，文字未读完也提供展开选项入口；行动仍经服务端确认，不能用阅读位置或旧对白重开已经错过的窗口。
